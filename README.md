# PNN Journal

PNN Journal is a one-page editorial experience about the people, ideas, and industries shaping what comes next. Through six visual stories, it explores industrial innovation, design, energy, engineering, and the future beyond the digital world.

The page uses a scroll-driven presentation: article sections reveal as readers move through the story, while the background color transitions to reflect each chapter. Editorial photography, pull quotes, and a minimal navigation frame the content.

## Stories

1. **The New Industrials** — industrial pioneers reshaping the physical world.
2. **A Different Kind of Future** — design and technology changing how industries are built.
3. **Beyond the Digital World** — innovation in laboratories, energy, factories, and infrastructure.
4. **Rebuilding Everything** — engineering and the next era of manufacturing and logistics.
5. **The Energy Transition** — changing how energy is produced and distributed.
6. **A World Reimagined** — how emerging industries may reshape society.

## Built with

- [Next.js](https://nextjs.org/) App Router
- React
- TypeScript
- Tailwind CSS 4 via the PostCSS plugin

Article photography is loaded from [Unsplash](https://unsplash.com/), so images require an internet connection.

## Run locally

Use Node.js and npm, then install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production

Build and run the production version:

```bash
npm run build
npm start
```
